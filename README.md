# AI Assistants Web

A single-file, self-contained 3D developer portfolio built with Three.js and GSAP.

## Features
- Interactive Three.js hero canvas: a glowing wireframe "SaaS data structure" cube with a node-graph lattice that responds to mouse movement and scroll
- Dark, high-contrast dev-platform aesthetic (Space Grotesk + JetBrains Mono)
- Core capabilities, selected projects, animated tech-stack terminal, and a terminal-styled contact form
- Fully responsive, with a static fallback if WebGL is unavailable

## Tech stack
- HTML5 / CSS3 (no build step)
- [Three.js](https://threejs.org/) r128 (CDN)
- [GSAP](https://gsap.com/) + ScrollTrigger (CDN)
- Google Fonts: Space Grotesk, JetBrains Mono

## Running locally
No build tools required — it's a single HTML file.

1. Download `index.html`
2. Open it directly in any modern browser, or serve it with any static host

## Deployment
Works on any static host (GitHub Pages, Netlify, Vercel) since it has no server-side dependencies.
